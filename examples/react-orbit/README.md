# React Orbit adapter example

[`App.tsx`](./App.tsx) is a strict-typed integration example for `@subjective-c/react`. It demonstrates the provider/root bridge, a policy-constrained mutation, persisted runtime preferences, nested routes with parallel loader support, and static server output.

The monorepo typecheck includes this example. A consuming React 19 application must import `@subjective-c/runtime/styles.css` once in its client entry point.
