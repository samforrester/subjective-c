# Orbit example

Orbit is the reference Subjective C application. Its source is an English product brief in `app.subjective`; the config supplies example data and a starting user context.

From the repository root:

```bash
npm run dev
```

Try these in the runtime inspector:

1. Switch the user model between novice, returning, and expert.
2. Move novelty from 20% to 90%.
3. Rewrite the intent and press **Compile intent**.
4. Press **Reinterpret** or use the `R` shortcut.
5. Lock a seed, refresh, then unlock it.
